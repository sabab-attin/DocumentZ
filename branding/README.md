# DocumentZ logo

`documentz-logo.png` is the supplied primary artwork. Android launcher and monochrome layers, Windows ICO resources, web icons and the store icon are derived from it. There are no selectable alternate logos.

Android uses an opaque white adaptive background and a transparent foreground. The monochrome layer uses the same artwork alpha, with internal white areas cut out so the launcher can apply its own colors. Artwork is kept inside the adaptive icon safe area. Pixel Launcher and Samsung One UI still control masking, tint and icon caching; custom third party theme packs may replace an app icon themselves.

Legacy Android launcher alias names remain only to preserve upgrades from installations that selected an older icon. They all point to the new artwork and normalize to the primary entry after launch. Do not remove those component names without an upgrade migration plan.
